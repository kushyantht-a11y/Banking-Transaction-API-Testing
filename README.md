# Banking Transaction Management API

## Project Overview
A REST API developed using Java and Spring Boot to manage basic banking transactions.

## Technologies Used
- Java 17
- Spring Boot
- Maven
- Eclipse IDE
- Postman
- JUnit 5

## Features
1. Create Bank Account
2. Deposit Money
3. Withdraw Money
4. Check Account Balance
5. Validate Invalid Transactions

## API Endpoints

| Method | Endpoint | Purpose |
|---|---|---|
| POST | /api/accounts | Create account |
| POST | /api/accounts/{id}/deposit | Deposit |
| POST | /api/accounts/{id}/withdraw | Withdraw |
| GET | /api/accounts/{id}/balance | Check balance |

## Testing
- Postman API Testing
- JUnit 5 Integration Testing
- Positive and Negative Test Cases

## How to Run
1. Import the project into Eclipse as an Existing Maven Project.
2. Update Maven dependencies.
3. Run BankingApiApplication.java.
4. Open Postman and execute the collection.
